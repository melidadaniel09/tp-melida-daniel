# Portal de Ubicaciones — Rick & Morty

**Autor:** Jesús Daniel Melida González  
**Variante:** B · Ubicaciones  
**Asignatura:** Fundamentos de Desarrollo Web — 2026  

## Descripción

Buscador de ubicaciones del universo de *Rick and Morty* que consume la [API pública oficial](https://rickandmortyapi.com/). Permite filtrar por **nombre** y **tipo** de ubicación, y muestra los resultados en una grilla de tarjetas responsiva.

Cada tarjeta muestra:
- Nombre de la ubicación
- Tipo (Planet, Space station, etc.)
- Dimensión
- Cantidad de residentes

La última búsqueda se recuerda con `localStorage` y se repite automáticamente al recargar la página.

## Tecnologías

- HTML5 semántico
- CSS3 (Grid, Flexbox, variables CSS, diseño responsivo)
- JavaScript ES6+ (`fetch`, `async/await`, `localStorage`)
- API: [Rick and Morty API](https://rickandmortyapi.com/documentation/#location)
